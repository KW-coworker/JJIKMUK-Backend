# 개발자 시험용 외부 AI 일괄 허용

개발자만 사용하는 기간에 운영자가 외부 AI 사용을 일괄 허용할 수 있다. 2026-11-03 별도 승인으로 운영한 기능을 정식 코드로 반영한다. 개별 사용자의 동의를 수집했다는 기록을 생성하는 기능은 아니다.

- 기본값은 OFF다. 기존 API 동의 동작을 유지한다.
- `CHATBOT_DEVELOPER_TEST_AUTO_CONSENT=true` 또는 JVM 옵션 `-Dchatbot.developer-test-auto-consent=true`로 켠다. 기존 운영 JVM 옵션과 호환된다.
- ON이면 인증된 챗봇 요청의 동의 누락/null/false/true를 모두 외부 AI 허용으로 서명한다. 문자열/숫자 등 잘못된 타입은 계속 400이다.
- JWT 인증·소유자 검사·내부 토큰·정확한 요청 바이트의 HMAC·v2 계약·요청 크기 제한은 유지된다. 익명 사용자는 401이다.
- 원본 요청의 동의값이나 DB의 사용자 동의 기록을 변경하지 않는다. 시작 시 운영자 허용 정책임을 경고한다. 외부 AI 호출 한도와 생성/발췌 모드는 바꾸지 않는다.

코드 병합만으로 운영 옵션이 켜지거나 서버가 배포되지 않는다. 현재의 개발자 시험 정책을 유지하는 배포 설정은 별도 승인 후 연결한다. 자동 만료는 없으므로 일반 사용자를 받기 전에 운영자가 종료 여부를 확인해야 한다.

종료하려면 실제로 적용 중인 JVM 옵션/환경 설정을 false로 바꾸고 백엔드를 재시작한다. JVM 옵션이 환경변수보다 우선할 수 있어 둘 다 확인한다. 그 뒤 앱이 실제 동의값을 보내는지 확인한다. 이 설정 변경과 재시작도 운영 승인을 거친다.

검증은 로컬 가짜 AI HTTP 서버와 H2를 사용한다. 실제 외부 AI나 운영 DB를 호출하지 않는다. 기존 기본 OFF 검사와 신규 ON 검사 모두 유지한다.
