# 진행 중 상품 작업의 짧은 읽기 진단

먼저 `catalog-live-meta`로 run `42984831949`의 고정 S3 실행 기록을 읽고 SHA-256만 받습니다. 이 조회에는 SSM 명령이나 DB 접속이 없습니다. `catalog-live`는 그 해시를 `work_sha256`에 고정하여 기록 전체·유지보수 잠금·원본 커밋·저장된 패키지를 대조한 뒤, 기존 백엔드 한 대에서 고정 읽기 명령을 실행합니다. 이 두 읽기 모드만 별도 실행 그룹을 사용하며 기존 변경 작업은 모두 같은 직렬 대기열을 유지합니다.

서버의 기존 TLS 연결 코드로 DB에 한 번 연결하여 같은 DB 계정의 실행 중 명령 종류와 전역 엔진 숫자 카운터를 5회, 약 8초간 관찰합니다. 출력은 미리 정한 종류·관측 횟수·경과 초·카운터 차이뿐입니다. SQL 원문, 상품·회원 데이터, 비밀번호는 출력하지 않습니다. 기존 설치 패키지를 읽으며 새 라이브러리를 다운로드하지 않습니다. 전체 호스트 진단은 40초 제한입니다.

새 SSM 문서·실행 기록은 생성합니다. 상품 변경 SQL, 서버 서비스 조작, 진행 중 명령의 중단·재시작·제한 시간 변경은 없습니다. 정상 유지보수 잠금은 기존 소유자 그대로 유지합니다. 지표는 지연 원인을 좁히는 자료이며 그 자체로 원인을 확정하지 않습니다.
