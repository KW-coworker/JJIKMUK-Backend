# FULLTEXT 보존 정비 사전 점검

사용자는 2026-11-10에 기존 검색 설계를 유지하는 FULLTEXT 임시 제거·테이블 물리 재구성·원본 V17~V20 적용·동일 인덱스 복원을 승인했습니다. 이 PR은 그 정비의 **읽기 전용 선행 점검**입니다.

기존 GitHub 연결에서 서버 1대에 고정 명령을 한 번 실행합니다. 기존 검증 라이브러리를 재사용하며 새 앱 파일이나 라이브러리를 설치하지 않습니다. 현재 앱의 DB 연결로 TLS 검증을 유지하며 다음만 확인합니다.

- products의 정확한 FULLTEXT 컬럼·ngram 파서·토큰 설정과 DDL 해시
- products·rollback 테이블의 예상 행 수와 할당 크기, 전체 스키마 크기
- 현재 DB 계정에 직접 부여된 정비 필요 권한의 충족 여부
- 현재 계정에 보이는 다른 DB 세션 개수

SQL 값·계정명·권한 원문·상품/사용자/대화 내용은 결과에 넣지 않습니다. `DATA_FREE`는 RDS 디스크 여유 공간이 아니며, 보이는 세션 수는 쓰기 중단의 증거가 아닙니다. 역할로 부여된 권한은 이 점검에서 직접 권한으로 간주하지 않습니다. 미확인 조건은 실제 변경 전 별도로 해소합니다.

DB 변경·스냅샷 생성·서비스 중단/재시작·배포·자동 CD 활성화는 이 고정 명령에 포함하지 않습니다. 기존 소비된 점검 계획은 그대로 보존합니다.
