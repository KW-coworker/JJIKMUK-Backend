# 이미지 작업을 중단한 상태에서 백엔드 CD 재개

2026-11-12 사용자는 이미지 작업 중단 유지, 백엔드 CD 보류 해제, PRE_REPO `chatbot` 최신 배포·검증 및 자동 CD 활성화를 승인했다.

`resume-paused-images`는 취소된 이미지 실행 43069183840의 완료 경계를 받아들이는 전용 절차다. 원래 자료 전체 적용 성공으로 기록하지 않는다. 241,000건 확인·236,207건 변경·857,863건 미처리를 유지한다.

1. 기존 유지보수 요청·실행 식별자와 GitHub 취소 완료를 확인한다.
2. 양쪽 서버의 진행 중 SSM 명령이 없는지 확인한다.
3. 공용 호스트 잠금 안에서 완료된 13개 이미지 묶음의 결과·입력 해시를 대조한다. 다음 묶음의 폴더가 있거나 미완료 결과가 있으면 보류를 유지한다.
4. 설치된 백엔드의 원본·환경·DB 구조·서비스 응답을 기존 검사기로 확인한다. 챗봇의 경로·소스 해시·CD 설치 파일 존재 여부도 읽는다. 비밀값은 출력하지 않는다.
5. 증거를 보존한 뒤 기존 보류를 `WORKING`에서 `VERIFIED`로 바꾼다. 아직 자동 CD는 열리지 않는다.
6. 기존 백엔드 CD로 최신 main을 배포·검증한 뒤 기존 `finish`로 `OPEN` 전환한다. 실패하면 보류가 유지된다.

이 작업은 이미지 추가 변경, 전체 상품자료 적용, 챗봇 설치·재시작, 유료 AI 호출을 하지 않는다. 챗봇 최초 전환은 관측 결과와 원본 호환성을 확인한 후 별도 고정 실행안으로 이어간다. 나중에 이미지 작업을 재개할 때는 변경된 실행 기준을 확인하고 미처리 구간 전용 계획을 사용해야 한다.
