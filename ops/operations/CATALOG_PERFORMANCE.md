# 상품 반영 중 성능 지표 조회

`server-operations.yml`의 `performance`는 지정 백엔드 EC2와 RDS의 최근 90분 CloudWatch 지표 15개만 읽습니다. 기존 서울 리전 `GetMetricStatistics` 권한을 사용하며 SSM 명령, SQL 접속, 설정 변경을 수행하지 않습니다. 출력은 5분 간격의 수치와 시각뿐이며, 값이 없으면 `NO_DATA`로 기록합니다.

진행 중인 상품 반영을 방해하지 않도록 이 읽기 모드만 별도 동시 실행 그룹을 사용합니다. 기존 배포·변경·조회 모드의 동시 실행 그룹과 승인 조건은 유지합니다. `production` 환경 승인 및 정확한 main 커밋 확인 후 실행하고, 결과는 기존 `storage-read` 비공개 실행 산출물의 `performance.json`에 저장됩니다.

조회 결과만으로 원인을 단정하지 않습니다. CPU 여유, 메모리, 디스크 대기·지연·처리량과 크레딧 추세를 실제 상품 처리 시간과 함께 비교합니다. 현재 진행 중인 적용 명령이나 제한 시간은 바꾸지 않습니다.
