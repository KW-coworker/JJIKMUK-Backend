# 상품 적용 중단 상태 읽기

run 42942707829는 적용 단계에서 CONNECTIONCLOSEDERROR, 복구 단계에서 일반 중단 코드로 종료됐다. 기존 고정 조회에서 백엔드는 active가 아니고 챗봇·Nginx·OCR 프로세스는 active였다. 현재 상품 값 복구 완료와 백엔드 정상 상태는 확인되지 않았다.

`catalog-state`는 이 실행의 정확한 binding SHA, S3 보류 상태, 원격 코드 해시와 종료된 unit을 확인한 뒤 잠금 아래 읽는다. 원래 실패 실행과 이미 소비한 점검은 그대로 둔다.

- 상태·저널의 해시, 생산자가 기록한 단계·건수, SQLite 상태별 건수만 수집한다. SQLite는 읽기 전용이며 sidecar가 있으면 열거나 복구하지 않는다.
- DB 구조와 Flyway V21 여부만 읽는다. 상품 값·회원·채팅 내용과 비밀값은 출력하지 않는다.
- 서비스·현재 포인터·보호 파일·디스크, 지정 unit의 제한된 로그에서 고정 오류 분류만 수집한다. 로그 원문·설정·접속값은 출력하지 않는다.
- 300초 종료 제한, SSM 360초. 앱 정지·기동·배포, DB 쓰기, Flyway repair, 저널 수정·재실행은 없다.

점검 성공은 읽기 완료를 뜻한다. 서비스 정상이나 상품 복구 완료를 뜻하지 않는다. 실제 DB 변경·복구 범위는 기록과 별도의 값 검증으로 판단한다.
