# 지정 상품 이미지 목록 적용

2026-11-12 사용자 승인: product-image-urls.txt의 1,098,863개 ID에 제공된 이미지 URL을 적용한다. 상품 12086도 파일 값으로 변경한다. 원본 SHA-256은 aa402ea6c9a0be6cfdc6f1f214ce0aa4a12c08f75d032a5a367d113b671672dc다.

입력은 기관 비공개 S3에만 보관한다. 공개 계획에는 파일 해시·버전·ID 구간·건수만 기록한다. 처음 1,000건 이후 최대 20,000건씩, 각 명령 안에서는 500건씩 잠금·전값 기록·저장·읽기 확인한다. 동일한 URL은 건너뛴다. 실제 상품 사진인지 참고 사진인지의 구분 필드는 이번 작업에서 변경하지 않는다.

변경 범위는 image_url, 해당 URL에서 원본 앱 규칙으로 파생되는 product_group_key, 새 관찰 기록을 가리키는 attribute_snapshot_id다. 다른 상품 필드를 전수 비교한다. 서비스 중지·재시작·JAR 배포·DB 구조 변경·CD 재개는 없다.

실패 시 이미 완료한 묶음을 유지하고 다음 쓰기를 중단한다. 같은 실행 재전송은 금지한다. 미확정 COMMIT은 기존 연결과 다른 연결의 잠금 읽기로 이전/이후 상태를 구분한다. 불일치나 잠금 시간 초과는 미확정으로 유지한다. 자동 이어하기·전체 자동 롤백은 구현하지 않는다. 부분 실패 후에는 실제 마지막 상태와 비공개 before/after 저널을 대조한 별도의 고정 복구/이어가기 계획이 필요하다.

RDS는 남은 대상당 8,000바이트와 최소 2GiB 여유를 확인한다. 이 추정은 로컬 측정 테이블 증가량의 약 4배이며 보장치는 아니다. 호스트는 최소 2GiB 여유를 유지한다. 각 명령 전 새 공간 지표를 확인하고 진행 건수는 GitHub 검사 화면에 갱신한다.

초기 백엔드 커밋 70dc1a70fff94dd0bee30f34638a15add23c0f26 및 기존 유지보수 WORKING 요청을 고정한다. 기존 단건 작업·전체 카탈로그 적용 작업을 재실행하지 않는다. 이미지 URL의 형식과 ID는 검증했지만 모든 외부 사진 URL의 현재 접근성·실제 상품 일치는 검증 범위 밖이다.
